## 🚀 Run Locally

No backend or package installation is required.

### Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Open `index.html` directly in a browser, or use **VS Code Live Server**.

### Using Live Server

1. Open the project in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 📤 GitHub Workflow

After making changes:

```bash
git status
git add .
git commit -m "Update portfolio"
git push
```

### First Push

```bash
git init
git add .
git commit -m "Initial portfolio release"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

### If Push Is Rejected with "fetch first"

If the GitHub repository already contains a README or another commit:

```bash
git pull origin main --allow-unrelated-histories
git commit -m "Merge remote repository"
git push -u origin main
```

## 🚀 GitHub Pages Deployment

1. Push the project to GitHub.
2. Open the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Click **Save**.
6. Wait for GitHub Pages to build the website.
7. Open the generated Pages URL.
